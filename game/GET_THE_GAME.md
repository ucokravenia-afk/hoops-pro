# Get the game

## Recommended

Download **`HOOPS_PRO_PREMIUM.html`** from the Grok chat artifact (Finishing release, ~514 KB).

Open with Chrome / Edge. No build step.

## Optional BGM

Put `derozia_eternal.mp3` next to the HTML.

## CrazyGames

1. Zip the HTML (and mp3 if any)
2. Submit on developer.crazygames.com
3. Set `window.HOOPS_CG_ENCRYPTION_KEY` from Leaderboard settings

See `docs/CRAZYGAMES_SDK.md`.

## Version

`1.0.0-premium-browser` — see root `VERSION` and `CHANGELOG.md`.
