# Game build

Full `index.html` is the HOOPS// PRO single-file game (~450KB).

If `index.html` is not yet in this folder, open the file from your Grok artifacts download (`HOOPS_PRO_PREMIUM.html`) and rename/copy to `index.html` here, then commit.

Grok + GitHub skill `hoops-pro-github` can sync it from the session workspace.
