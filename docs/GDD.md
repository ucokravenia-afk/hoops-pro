# HOOPS// PRO — Game Design Document (Structured)

**Version:** 1.0 foundation  
**Platform:** Browser (desktop + mobile)  
**Scope rule:** Ship working systems before expanding scope.

## 1. Vision
Premium *browser* basketball with career + manager depth. Not a 1:1 NBA 2K clone.

## 2. Pillars
Feel, Clarity, Depth, Performance — see full GDD in release package.

## 3. Core Loop
Hub → Match → Rewards → Meta → Hub

## 4. Modules (MVC)
Match, Career, Manager, Collection, Meta RPG, Platform — UI never writes physics; match never owns career format.

## 5. Priority
P0 Motion blend + shot feel · P1 Role AI · P2 Presentation

## 6. Roadmap
Phase A Foundation → B Polish → C Expand (online last)

## 7. Non-goals
Open-world city day-1, licensed NBA photo DB, fake 1TB installs.
