# Controls — Laptop / PC / Touch / Gamepad

## Desktop (keyboard)

| Action | Default |
|--------|---------|
| Move | WASD / Arrows |
| Sprint | Shift (hold) |
| Shoot | Space (hold & release for meter) |
| Pass | P / J |
| Steal | E / F |
| Block / Contest | R / B |
| Pivot | V (hold) |
| Switch player | Q / Tab |
| Auto press | X |
| Timeout | T |
| Coach challenge | C |
| Pause / Menu | Esc |
| Controls guide | F1 / H |

## Gamepad (Xbox layout)

- Left stick: move
- A: shoot
- X: pass
- B: steal
- Y: block
- RT: sprint
- RB: switch player

## Mobile

Virtual joystick + on-screen buttons. Left-hand mode in Settings.

## Menu

**Keyboard / Controls (F1)** from main menu.
