# Foundation Policy

No random feature expansion until foundation gates pass.

Modules: Presentation, Input, Gameplay, Data, Persistence, Live ops (curated events), Platform.

Save keys split: career, manager, rpg, settings, events, card favs, onboard.

Event catalog in-game is curated (7 daily / 5 weekly / 4 seasonal) — full master list is design inspiration only.

Gates: boot	o title	o menu	o PLAY	o match; career/manager save; collection; daily claim once; keyboard+touch.
