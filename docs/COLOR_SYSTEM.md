# Color system — HOOPS// PRO

Premium elegant, not neon arcade.

| Token | Hex | Role |
|-------|-----|------|
| `--neon` | `#d4af37` | Champagne gold (primary accent) |
| `--neon2` | `#8ec5c5` | Soft teal (secondary) |
| `--paper` | `#f3f1ec` | Platinum text |
| `--hot` / `--red` | `#e07060` | Soft alert |
| `--green` | `#6bcf9b` | Success / fitness |
| `--ink` | `#07090d` | Deep background |

Club jersey colors on the **court** stay unique per team. UI chrome uses this system so menus feel expensive without fighting team identity.
