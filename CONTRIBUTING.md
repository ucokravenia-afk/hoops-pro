# Contributing to HOOPS// PRO

## Workflow (Grok + GitHub)

1. Edit HOOPS_PRO_PREMIUM.html in Grok artifacts.
2. Syntax-check inline script with Node.
3. Ask Grok to push update ke GitHub (skill hoops-pro-github).
4. Prefer branches feat/... then PR into main.

## Code rules

- Surgical patches, do not rewrite the whole IIFE.
- Every UI control must mutate save state.
- Stay HTML5 2D; Unity folder is optional future path.
- No secrets in commits.

## Play test

Open game HTML in Chrome. Quick Match + Manager transfer smoke test.
