# HOOPS// PRO

**Basket HTML5 yang ngebut.** Career life stages, manager + awards, live ops (Christmas & Idul Fitri), ranked, multi-bahasa, mobile touch, CrazyGames SDK.

> Drop the HTML. Full court. No excuses.

## Main sekarang

1. Ambil `HOOPS_PRO_PREMIUM.html` dari sesi Grok / release
2. Buka di **Chrome / Edge** (desktop atau HP)
3. Optional BGM: `derozia_eternal.mp3` di folder yang sama

```bash
git clone https://github.com/ucokravenia-afk/hoops-pro.git
```

- Live Ops: daily login, events, ranked MMR, coins
- i18n (10 bahasa) + settings
- Mobile joystick / sprint / switch
- Club crests + FC-style portraits (procedural)
